# ИИ-ассистент техроддержки
### Дипломный проект

**Тема:** ИИ-ассистент техподдержки.

**Описание:** данный ассистент упращает работу сотрудников компании, занимающихся поддержкой проектов. Запросы приходят из внешнего приложения, происходит анализ запроса на исторических данных, ищется и предлагается путь решения.
