# ИИ-ассистент техподдержки
### Дипломный проект

**Тема:** ИИ-ассистент техподдержки.

**Описание:** данный ассистент упращает работу сотрудников компании, занимающихся поддержкой проектов. Запросы приходят из внешнего приложения, происходит анализ запроса на исторических данных, ищется и предлагается путь решения. 

### PostgreSQL-контрактные тесты

По умолчанию `uv run python -m pytest` запускает JSON-вариант контрактных
тестов и безопасно пропускает PostgreSQL-вариант. Чтобы выполнить оба варианта,
задайте отдельную тестовую базу в `.env`:

```env
TEST_DATABASE_URL=postgresql+asyncpg://chat:chat@localhost:5432/chat_test
```

Имя базы должно содержать `_test` или оканчиваться на `test`. Никогда не
указывайте здесь development-базу Docker Compose `chat`: fixture создаёт и
удаляет прикладные таблицы только в явно назначенной тестовой базе.
